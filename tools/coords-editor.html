Adaugă fotografie Imagine header
Cum ajung coordonatele pe hartă:
  1. Selectează fotografia din listă.
  2. Click pe hartă în locul potrivit.
  3. Apasă Salvează în catalog (sus).
  4. Deschide harta.html — pin-urile sunt acolo.

Butonul scrie direct în data/photos.json și regenerează automat paginile. Nu mai e nevoie de export/import sau de alte comenzi.

Salvare manuală (serverul actual nu suportă scrierea directă):
  1. Selectează fotografia, click pe hartă.
  2. Apasă Exportă JSON.
  3. Rulează în terminal:
    node tools/set-coords.js --import ~/Downloads/coordinates.json
  4. Rulează npm run build și reîncarcă harta.html.

Vrei un singur click? Oprește serverul curent și pornește npm run serve, apoi reîncarcă această pagină: va apărea butonul „Salvează în catalog".
