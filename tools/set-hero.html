1. Imaginea de header curentă

Poți scrie orice cale din assets/img/…. Se acceptă și fișiere din assets/img/previews/ sau assets/img/portfolio/.

Se salvează în data/site-config.json și site-ul se regenerează automat.

2. Alege din imagini

Cum funcționează

Alegi o imagine → apeși „Setează ca imagine de header" → index.html este regenerat cu noua imagine. Setarea rămâne salvată în data/site-config.json, deci nu se mai pierde la npm run build sau la salvările din celelalte unelte.

Dacă alegi o imagine mare (peste ~1800px), se generează automat un preview în assets/img/previews/ pentru încărcare rapidă.
